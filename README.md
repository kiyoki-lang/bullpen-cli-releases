# bullpen-cli-releases

Binary releases for [bullpen-cli](https://github.com/BullpenFi/bullpen-cli).

## Install

```bash
# Homebrew (macOS / Linux)
brew install BullpenFi/tap/bullpen

# npm
npm install -g @bullpenfi/cli

# curl
curl -fsSL https://bullpenfi.github.io/bullpen-cli/install.sh | sh
```
